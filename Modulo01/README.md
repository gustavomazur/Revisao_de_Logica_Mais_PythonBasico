# Modulo 01 - Python Básico

Conteúdo do curso **Curso em Vídeo - Python Mundo 1**.
Exercícios praticados cobrindo saída, entrada, variáveis, matemática, módulos, strings, condicionais e cores no terminal.

## Pré-requisitos

- Python 3.x
- `pygame` (apenas para o exercício ex21 de áudio)
